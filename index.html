Set up your login

One-time setup. The CMS publishes by committing to your personal-rahul GitHub repo, so it needs a fine-grained token with Contents: Read and write on that repo — create one at github.com/settings/personal-access-tokens/new. Your password encrypts the token in this browser (AES-256); only the encrypted version is stored, and the password itself is saved nowhere. After setup you sign in with just the password — from any device.
